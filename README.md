Veebilehe teemaks on kasutajakogemuse (UX) elementide õpetamine. Üks alaleht on näide halvast UX-ist (näiteks keelatud nupp, millest pole aru saada, et see on keelatud). Teine näide on hea UX. Peamine leht selgitab mõlemaid näiteid lahti. Peamine funktsionaalsus, mille kaudu selgitame, on kontaktivorm. Kontaktivormi vastuste salvestamiseks on Pythonil ehitatud backend, millega suhtlemine käib JavaScripti kaudu. See salvestab vastused  SQLite andmebaasi. Lisaks on kasutajakontod (mida saab lihtsuse huvides lisada ainult otse andmebaasi, parooli hashimine käib Argon2-ga, mida tuleb konto loomisel käsurealt kasutada), millega saab küsida vastuste JSON-it (autentimiseks Basic Auth).
